# Lio — Releases

Signed and notarized macOS builds for [Lio](https://www.lioplayer.com), an audio
player made for musicians — slow songs down, loop the tricky bits, and shift the
pitch so you can learn and rehearse any track.

Source is private.

Each release here is a tag anchor for a versioned DMG. To download the latest
build, visit [lioplayer.com](https://www.lioplayer.com). The app's built-in
"Check for Updates…" pulls from the same Sparkle feed, so it keeps itself current.
