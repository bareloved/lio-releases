# The Player — Releases

Signed and notarized macOS builds for [The Player](https://www.lioplayer.com).

Source is private.

Each release on this repo is a tag anchor for a versioned DMG. To download the
latest build, visit [lioplayer.com](https://www.lioplayer.com) — the in-app
"Check for Updates…" menu pulls from the same Sparkle feed.
